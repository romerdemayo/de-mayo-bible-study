VERSION 91 — PRESENTATION LANGUAGE SOURCE FIX

- Built-in Devotionals, Exhortations, Bible Studies and Kids Lessons now carry both English and Tagalog presentation variants when presentation starts.
- Language switching no longer tries to reconstruct Exhortations or Bible Studies from the current screen.
- Sermon Studio keeps custom sermon text visible because custom sermons do not contain an automatic offline translation.
- Read Bible Tagalog still requires its Bible dataset to have been downloaded once; the app prevents blank presentation if it is unavailable.
