## Main features

- English and Tagalog Bible reading
- Search, favourites, highlights, and editable verse notes
- Editable devotionals, exhortations, Bible studies, kids lessons, and prayer library
- AI-assisted study notes, prayer journal, sermon preparation, and prayer improvement
- Sermon and children’s presentation outlines
- Kids ministry resource packs
- Local backup and restore

## Deploy to GitHub Pages

Upload the **contents inside** the `de-mayo-bible-study-main` folder to the root of the GitHub repository. The repository root must directly contain `index.html`, `app.js`, `styles.css`, and `service-worker.js`.

In GitHub, open **Settings → Pages**, select the `main` branch and `/root`, then save.

Live site: `https://romerdemayo.github.io/de-mayo-bible-study/`
