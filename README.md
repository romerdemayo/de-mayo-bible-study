# De Mayo Bible Ministry — Version 7

An installable, offline-first Bible and ministry resource app designed for GitHub Pages.

## Included

- Complete offline King James Version Bible
- 30 devotionals
- 20 exhortations
- 15 Bible studies
- 20 children’s lessons
- 30 prayers
- Universal resource search and Bible search
- Highlights, favourites, verse notes, study notes, prayer journal, sermon builder, kids planner and reading tracker
- Offline resource creator and ChatGPT prompt builder without an API key
- Private **My Resources** stored in each browser profile
- Backup and restore
- Installable PWA for phones, tablets and desktop computers

## Privacy

Personal notes and resources use browser local storage. They are not uploaded to GitHub. Data is separate per browser profile/device, but is not account-based. Use the backup feature to move personal data to another device.

## Publish using GitHub Pages

1. Create or open a GitHub repository.
2. Upload every file and folder from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. The included workflow publishes the site automatically after each push to `main`.

You can also choose **Deploy from a branch** and use `/ (root)` if preferred.

## Updating

Replace the existing files with a newer release and commit the changes. The service worker cache name is versioned so users receive the update after refreshing.

## Important ministry note

All generated or preloaded teaching materials should be reviewed carefully against Scripture and your church’s doctrine before public ministry use.
