DE MAYO BIBLE STUDIES — VERSION 50

This package keeps the GitHub Pages website and adds:
- Improved installable PWA support
- iPhone/iPad Home Screen icon
- Android maskable icons
- Better offline caching
- Capacitor configuration for native iOS and Android projects
- App Store and Google Play preparation guides

For GitHub Pages: upload the website files as usual. The package.json, capacitor.config.json, scripts, and native-app folder may remain in the repository.

Important: uploading to GitHub does not automatically publish to the Apple App Store. Apple requires an Apple Developer Program membership unless an eligible organisation receives a fee waiver.
