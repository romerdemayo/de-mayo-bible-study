DE MAYO BIBLE STUDIES — VERSION 61
SIMPLER BIBLE STUDY DASHBOARD

WHAT CHANGED
- Removed the forced “Today’s Journey” checklist.
- Removed Prayer Journal and Reflection requirements from the Home dashboard.
- The dashboard now uses only features already available in the app.
- Added Continue Reading, Verse of the Day, Bible progress, reading streak,
  highlights, verse notes, guided plan status, favourite verse, and quick actions.
- Guided Reading Plan progress appears only after a plan has actually been started.
- If no plan is active, the dashboard simply offers a View Plans button.
- Updated the service-worker cache to Version 61.

INSTALLATION
Upload every file and folder in this package to the root of the GitHub repository,
replacing the previous version. After GitHub Pages updates, refresh twice or close
and reopen the installed app so the Version 61 cache is loaded.
