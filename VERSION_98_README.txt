DE MAYO BIBLE STUDIES — VERSION 98
SCRIPTURE LINK QUALITY ASSURANCE RELEASE

This release standardises clickable Scripture references throughout the app.

IMPROVEMENTS
- One shared Bible-reference parser for normal pages and Presentation Mode.
- Supports all 66 canonical Bible book names.
- Supports Psalm and Psalms.
- Supports Song of Songs, Song of Solomon, Songs, and Canticles.
- Supports common abbreviations such as Ps, Gen, Matt, Jn, Rom, 1 Cor, and 1 Jn.
- Supports numbered books such as 1 Samuel, 2 Corinthians, and 3 John.
- Supports chapters, individual verses, verse ranges, and cross-chapter ranges.
- Rejects chapter and verse numbers outside the bundled WEB Bible.
- Guided Reading Plan Read buttons use the same parser as every other Scripture link.
- Presentation Mode Scripture links use the same parser as the main app.
- Offline cache updated to Version 98.
