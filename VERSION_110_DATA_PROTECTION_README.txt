DE MAYO BIBLE STUDIES — VERSION 110 DATA PROTECTION

Added:
- Automatic IndexedDB device snapshot after saved changes
- Startup recovery when localStorage unexpectedly becomes empty but the device snapshot remains
- Manual Protect Data Now and Recover Device Snapshot controls
- Last automatic device-backup status
- Browser persistent-storage request where supported
- Working service-worker.js with a new Version 110 cache
- Strong warning to download a JSON backup before deleting/reinstalling the Home Screen app
- Backup snapshots refreshed after restores

IMPORTANT LIMITATION
Deleting an iPhone Home Screen web app can cause iOS to remove both localStorage and IndexedDB. No browser-only feature can guarantee recovery after that. Download My Data remains the reliable portable backup for reinstalling or moving devices.
