VERSION 89 — OFFLINE PRESENTATION LANGUAGE STABILITY

Fixed:
- Built-in Exhortations and Bible Studies now build presentations directly from bilingual source data.
- Switching English/Tagalog no longer depends on copied page HTML.
- Sermon Studio and personal content stay visible when language changes; custom writing is not falsely auto-translated offline.
- Read Bible and Bible-passage presentations remain in English with a clear message when Tagalog Bible has never been downloaded and the device is offline.

Important:
The Tagalog Bible is currently downloaded on first online use and then cached. A brand-new extracted folder opened fully offline cannot download it. Connect once, select Tagalog, and thereafter it can be available from browser storage/cache.
