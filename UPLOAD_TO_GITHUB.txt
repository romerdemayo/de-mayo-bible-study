UPLOAD TO GITHUB
================

1. Unzip this package.
2. Open your GitHub repository: de-mayo-bible-study
3. Upload ALL files and folders from inside this project folder.
4. Commit directly to the main branch.
5. Go to Settings > Pages.
6. Choose GitHub Actions as the source.
7. The included workflow will deploy the app.

Your website should remain at:
https://romerdemayo.github.io/de-mayo-bible-study/

After deployment, refresh twice or clear the old site cache if Version 6 still appears.
