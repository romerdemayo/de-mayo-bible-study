DE MAYO BIBLE STUDIES — VERSION 37

Built from the runtime-fixed Version 36.

NEW FEATURE
- Sermon Studio now includes a PowerPoint Outline button.
- Creates an editable 13-slide presentation suggestion.
- Includes title, passage, purpose, introduction, context, three main points,
  Christ/Gospel connection, application, reflection questions, conclusion,
  closing prayer, and presentation guidance.
- English and Tagalog supported.
- The outline appears in a separate workspace and does not overwrite the sermon.
- Copy button provided for pasting into Microsoft PowerPoint or Google Slides.

This feature creates a presentation outline only. It does not automatically create a .pptx file.
