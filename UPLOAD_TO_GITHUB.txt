DE MAYO BIBLE STUDIES — VERSION 12

1. Extract this ZIP.
2. Open your GitHub repository: de-mayo-bible-study
3. Upload ALL files and folders inside this folder to the repository root.
4. Replace the existing versions when prompted.
5. Confirm GitHub Pages deployment is complete.
6. Open: https://romerdemayo.github.io/de-mayo-bible-study/
7. Refresh the browser. On iPhone, remove the old Home Screen app and add it again if required.

Do not delete bible-data.js. It contains the built-in KJV Bible used by the app.
