De Mayo Bible Studies Version 65 - Simple Kids Ministry Studio

What changed:
- Kids Ministry Studio now uses a simple form with optional title, passage, memory verse, age group, and lesson theme.
- Leaving fields blank creates a complete random Bible lesson.
- Each draft includes an opening prayer, lesson aim, Bible story guide, teaching points, questions, memory verse, activity, craft, weekly challenge, conclusion, and closing prayer.
- Saved lessons now go directly into the Kids Lessons library.
- Personal lessons can be opened, edited, copied, or deleted.
- The saved Bible passage is clickable and opens the Bible reader.
- Personal lessons remain private in the user's browser/device.
- Service-worker cache updated to Version 65.

Recommended testing branch: feature/simple-kids-ministry-studio
