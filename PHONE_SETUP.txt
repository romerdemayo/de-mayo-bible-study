DE MAYO BIBLE MINISTRY — PHONE INSTALLATION (NKJV ONLINE)

This Progressive Web App must be hosted on an HTTPS website such as GitHub Pages. Internet access is required whenever Bible passages or Bible searches are opened in the New King James Version (NKJV).

IPHONE / IPAD
1. Open the live GitHub Pages address in Safari.
2. Tap Share (the square with the upward arrow).
3. Tap Add to Home Screen, then Add.
4. If an older version appears, delete the old Home Screen app, clear the website data for github.io, and add it again.

ANDROID
1. Open the live address in Chrome.
2. Tap the browser menu.
3. Choose Install app or Add to Home screen.

WINDOWS / MAC
Open the live address in a modern browser. Chrome or Edge may show an Install icon in the address bar.

IMPORTANT
- Every Bible reading link and Bible search uses NKJV online.
- The full NKJV text is not stored in the GitHub files.
- Notes, prayers, sermons, created resources, and reading progress stay in that browser profile.
- Use Backup & Restore before clearing browser data or changing devices.
